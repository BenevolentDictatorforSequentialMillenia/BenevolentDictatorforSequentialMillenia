> Guido van Rossum is a Dutch programmer who created Python and served as its "Benevolent Dictator for Life" for nearly thirty years until he was forced to abdicate in 2018 following vitriolic community backlash over the "walrus operator" (`:=` [PEP 572](https://peps.python.org/pep-0572/#syntax-and-semantics))—a feature that has since become widely adopted.
> Van Rossum's reign saw Python emerge from a niche scripting tool into the world's most dominant programming language, anchoring modern web frameworks, data science, and the global artificial intelligence boom.
